# Angelus Studio

Website and business platform for **Angelus Media Productions**, built with Next.js and
Payload CMS on PostgreSQL, designed to run on our own server.

- Public website, managed from the admin panel at `/admin`
- Role-based access for staff and clients (client portal, galleries, bookings and more to follow)

See [docs/development.md](docs/development.md) to run it locally,
[docs/demo-preview.md](docs/demo-preview.md) for a preview filled with demo data, and
[docs/planning/platform-analysis.md](docs/planning/platform-analysis.md) for the roadmap.
